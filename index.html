HTTomo documentation#

HTTomo is a Python framework for high-performance tomographic data processing. It coordinates distributed I/O and CPU/GPU processing through MPI and runs pipelines described in readable YAML files.

Where should I start?#

New to HTTomo?

Follow the 10-minute quickstart to download a small test dataset, validate a pipeline and run it from start to finish.

Preparing your own data?

Read Loading data, including how to create an HTTomo-compatible NXtomo file.

Building a pipeline?

Browse the ready-to-use pipelines, or configure one from available method templates.

Developing HTTomo or a method?

Start with Architecture and internals, then follow the contribution path that matches your change.
